## インストール

### 要件

- PHP >= 7.3
- Laravel >= 5.7

Orionは、composerの依存パッケージを追加するだけで、新規・既存どちらのプロジェクトにもインストールできます。

```bash
composer require tailflow/laravel-orion
```

```bash
php artisan vendor:publish --tag=orion-config
```

::warning
Composer v1を使用している場合、インストール時に次のエラーが発生することがあります。

<br/><br/>
`Installation error: Installation request for doctrine/dbal (locked at 3.0.0) -> satisfiable by doctrine/dbal[3.0.0]`

<br/><br/>

その場合は、Composerをv2にアップグレードする(推奨)か、Orionをインストールする前に`composer require doctrine/dbal`を実行してください。
::

## シンプルなCRUD

ブログ記事を表す`Post`モデルがあり、これをREST API経由で管理したいとします。

Orionを使えば、次の3つの簡単なステップで実現できます。

1. `PostsController`を作成し、`Orion\Http\Controllers\Controller`を継承します

```php
<?php

namespace App\Http\Controllers\Api;

use App\Models\Post;
use Orion\Http\Controllers\Controller;

class PostsController extends Controller
{

}
```

2. 次に`protected $model`プロパティを定義し、完全修飾のモデルクラス名を設定します。完成したコントローラーは次のようになります

```php
<?php

namespace App\Http\Controllers\Api;

use Orion\Http\Controllers\Controller;

class PostsController extends Controller
{
    /**
     * Fully-qualified model class name
     */
    protected $model = Post::class; // or "App\Models\Post"
}
```

::note{icon="i-lucide-lightbulb"}
デフォルトでは、Laravelの`app/Http/Controllers`に`Api`フォルダは含まれていませんが、コードを整理しておくために、このフォルダを作成してすべてのAPIコントローラーをそこに格納することをおすすめします。
::

::warning
APIで公開するモデルに対して[ポリシー](https://laravel.com/docs/authorization#creating-policies)を作成して登録するか、`DisableAuthorization`トレイトの使用(ローカルでのテスト専用)を検討してください。ポリシーが未登録または不正な場合に403エラーが発生するのを避けられます。
::

::warning
[リクエストクラス](/ja/guide/security#バリデーション)は、`Illuminate\Foundation\Http\FormRequest`ではなく`Orion\Http\Requests\Request`クラスを継承する必要があります
::

3. 最後に、`api.php`で`Orion::resource`を呼び出してルートを登録します

```php
<?php

use Illuminate\Support\Facades\Route;
use Orion\Facades\Orion;
use App\Http\Controllers\PostsController;

Route::group(['as' => 'api.'], function() {
    Orion::resource('posts', PostsController::class);
});

```

これで完了です。REST API経由でブログ記事の作成、一覧取得、検索、閲覧、更新、削除ができるようになりました。`(POST) https://<your app url>/api/posts`エンドポイントで記事を作成してみてください。
