---
title: レスポンス
description: モデルがJSONレスポンスに変換される仕組みについて学びます。
---

Orionは、Eloquentモデルと、APIクライアントに実際に返されるレスポンスとの間の変換レイヤーとして[APIリソース](https://laravel.com/docs/eloquent-resources)を使用します。

これらのクラスが自動的に解決されるようにするには、`App\Http\Resources\<model>Resource`または`App\Http\Resources\<model>CollectionResource`というパターンに従う必要があります。

たとえば、`App\Models\Message`モデルがある場合、関連するリソースクラスは`App\Http\Resources\MessageResource`または`App\Http\Resources\MessageCollectionResource`になります。

アプリ内のリソースクラス名がこの命名規則に従っていない場合や、より明示的に指定したい場合は、コントローラーの`protected $resource`または`protected $collectionResource`プロパティに、完全修飾リソースクラス名を設定します。

```php
<?php

namespace App\Http\Controllers\Api;

use App\Models\Message;
use App\Http\Resources\CustomMessageResource;
use App\Http\Resources\CustomMessageCollectionResource;

class MessagesController extends ApiController
{
    /**
     * @var string $model
     */
    protected $model = Message::class;

    /**
     * @var string $resource
     */
    protected $resource = CustomMessageResource::class;

    /**
     * @var string $collectionResource
     */
    protected $collectionResource = CustomMessageCollectionResource::class;
}
```

::note{icon="i-lucide-lightbulb"}
`Orion\Http\Resources\Resource`クラスと`Orion\Http\Resources\CollectionResource`クラスの両方で、便利な`toArrayWithMerge`メソッドが利用できます。ぜひ確認してみてください。
::
