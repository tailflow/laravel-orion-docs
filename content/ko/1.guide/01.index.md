## 동작 방식

Orion은 Eloquent 모델과 연관관계, 정책, 요청 클래스, API 리소스 등 Laravel의 가장 강력한 기능을 활용합니다. 덕분에 매우 강력하고 확장성이 뛰어나면서도 손쉽게 시작할 수 있습니다.

컨트롤러를 생성하고 API로 관리할 Eloquent 모델을 연결하기만 하면, 나머지 REST 처리는 Orion이 대신합니다. `index`, `search`, `show`, `store`, `update`, `destroy`, `restore` 및 `batchStore`, `batchUpdate`, `batchDestroy`, `batchRestore` 작업을 위한 모든 엔드포인트가 적절한 인가, 유효성 검사, 오류 처리와 함께 준비됩니다 (물론 정책과 요청 클래스는 직접 정의해야 합니다).

여기서 끝이 아닙니다. 연관관계 컨트롤러를 정의하면 API 소비자가 모든 유형의 연관관계를 관리할 수 있습니다. 말 그대로 전부입니다. 즉 `associate`/`dissociate`, `attach`/`detach`, `sync`, `toggle`, `updatePivot`은 물론 CRUD 작업까지 표준화된 REST API로 제공됩니다.

보너스로, 모델 컨트롤러와 연관관계 컨트롤러 모두에서 `search` 엔드포인트를 통해 다양한 쿼리 제약 조건을 적용하여 필터링된 결과를 조회할 수 있습니다.

## 기능

* 일괄 작업을 지원하는 [모델](/ko/guide/models) 및 [연관관계](/ko/guide/relationships) REST API
* [정렬](/ko/guide/search#정렬), [필터링](/ko/guide/search#필터링), [키워드 검색](/ko/guide/search#키워드-검색)을 갖춘 고급 검색 기능
* OpenAPI [명세](/ko/guide/specifications) 자동 생성
* 포괄적인 엔드포인트 [훅](/ko/guide/hooks) 지원
* 쿼리 파라미터를 통한 [연관관계 포함](/ko/guide/query-parameters#연관관계-포함) 및 [소프트 삭제](/ko/guide/query-parameters#소프트-삭제) 처리
* 간단명료한 [인가](/ko/guide/security#인가) 및 [유효성 검사](/ko/guide/security#유효성-검사)
* API 리소스를 통한 [응답](/ko/guide/responses) 변환
