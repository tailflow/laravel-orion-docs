## 工作原理

Orion 充分利用了 Laravel 最强大的特性：Eloquent 模型与关联、策略、请求类以及 API 资源，这使得它功能强大、易于扩展，同时上手非常简单。

你只需创建一个控制器，将它与想要通过 API 管理的 Eloquent 模型关联起来，剩下的 REST 工作就交给 Orion！`index`、`search`、`show`、`store`、`update`、`destroy`、`restore` 以及 `batchStore`、`batchUpdate`、`batchDestroy`、`batchRestore` 操作的所有端点都会自动就绪，并带有完善的授权、验证和错误处理（当然，策略和请求类需要你自己定义）。

但这还不是全部。定义关联控制器后，你的 API 使用者就可以管理所有类型的关联。是的，所有类型——这意味着 `associate`/`dissociate`、`attach`/`detach`、`sync`、`toggle`、`updatePivot` 以及 CRUD 操作都可以通过标准化的 REST API 使用。

此外，作为额外福利，模型控制器和关联控制器上的 `search` 端点允许应用各种查询约束来获取过滤后的结果。

## 功能特性

* 为[模型](/zh/guide/models)和[关联](/zh/guide/relationships)提供 REST API，并支持批量操作
* 高级搜索能力，支持[排序](/zh/guide/search#排序)、[过滤](/zh/guide/search#过滤)和[关键词搜索](/zh/guide/search#关键词搜索)
* 自动生成 OpenAPI [规范](/zh/guide/specifications)
* 全面的端点[钩子](/zh/guide/hooks)
* 通过查询参数[包含关联](/zh/guide/query-parameters#包含关联)和使用[软删除](/zh/guide/query-parameters#软删除)
* 简单直接的[授权](/zh/guide/security#授权)与[验证](/zh/guide/security#验证)
* 通过 API 资源对[响应](/zh/guide/responses)进行转换
